# AGENTS.md

This repository is a machine learning homework workspace for the DataTalks Club Machine Learning Zoomcamp.

## Project goals
- Keep solutions organized, readable, and easy to rerun.
- Prefer small, focused Python scripts or notebooks for each homework task.
- Maintain a clear README when new exercises or datasets are added.

## Working conventions
- Do not remove or overwrite user work without a clear reason.
- Keep changes minimal and scoped to the task.
- Favor explicit names, small functions, and readable comments.
- When adding code, prefer standard libraries plus common ML tools such as pandas, NumPy, scikit-learn, and Jupyter.

## Verification
- Run the smallest relevant validation command for the change.
- If a Python task is added, run the relevant script or test for that module.
- If a notebook is changed, validate that it can execute or at least parse without errors.

## Notes
- This repository is intentionally lightweight at the moment; add structure as needed for each homework assignment.
- Treat the README as the entry point for project context.
